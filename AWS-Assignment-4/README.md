AWS Assignment 4 – My First Serverless API Project
Introduction
For my fourth AWS assignment, I worked on building a serverless application using AWS Lambda, API Gateway, DynamoDB and CloudWatch.

As someone who is still learning AWS and Cloud Engineering, this was a new experience for me. I had never built something like this before, so I was excited to see how these AWS services could work together.

Some parts were confusing at first, but I took my time and worked through them step by step.

What I Did
In this assignment, I learned how to:

Create a DynamoDB table called students.
Set up an AWS Lambda function using Python.
Create a REST API using API Gateway.
Connect API Gateway to my Lambda function.
Create a POST method to send student information.
Deploy my API using the prod stage.
Test my API using AWS CloudShell.
Check DynamoDB to see whether the information was saved.
Use CloudWatch to check my Lambda logs.
What Went Wrong
Not everything worked perfectly the first time.

One problem I had was when I tested my API using a curl command in CloudShell.

I received a successful response, but I also got several error messages in the terminal.

At first, I wasn't sure why this was happening, especially because the API appeared to be working.

I also found some of the API Gateway settings confusing because there were several options I hadn't used before.

How I Fixed It
I went through the steps carefully and checked what I had configured.

I learned that the way commands are written in the terminal is important, especially quotation marks and JSON formatting.

To make sure my application was working, I checked DynamoDB and found that my student submissions had been saved.

I also checked CloudWatch and could see the Lambda function had been executed.

This gave me more confidence that I had connected the AWS services correctly.

What I Learned
This assignment taught me a lot of new things.

Before starting, I didn't really understand how an API could send information to a Lambda function and then save it in a database.

Now I have a better understanding of how these services work together.

I also learned that getting errors is part of learning. Instead of giving up, I need to understand what went wrong and find a way to fix it.

My Final Thoughts
I'm happy to have completed my fourth AWS assignment!

I'm still a beginner, and I know I have a lot more to learn, but every assignment is helping me become more comfortable using AWS.

The best part was seeing my API work and finding the information stored in DynamoDB.

I'm looking forward to continuing my DevOps and Cloud Engineering journey and building more projects as I improve my skills.
